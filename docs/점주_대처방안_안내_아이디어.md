# 점주 대처방안 안내 — 아이디어 및 프로토타입 구현

> **성격**: 공모전 프로토타입. 실제 사용자에게 제공하는 서비스가 아니다.
> 여기 적힌 제도·절차 안내는 공개 자료를 근거로 했지만, 실제 상담·신청은 반드시
> 한전 등 공식 창구를 통해야 한다.
> **작성일**: 2026-09-10 · 구현 위치: `src/ami_db/narrate.py`(OWNER_GUIDANCE, SYSTEM_PROMPT)

---

## 1. 문제 — "그래서 뭘 어쩌라는 거지?"

기존 알림은 감지 결과까지만 전달했다.

> "충북식당 점주님, 2026-07-02 02:15에 전력 사용량이 18.95kWh로 **계약전력(45kW)의
> 130% 임계치**(14.62kWh)를 초과했습니다. 안전 점검을 부탁드립니다."

여기엔 두 가지 문제가 있다.

### 1-1. 용어가 통하지 않는다

**계약전력은 상업용 전기에만 있는 개념**이다. 가정용(주택용)은 계약전력 없이 사용량
누진제만 적용되므로, 가정용 전기만 써 본 사람에게 "계약전력의 130%"는 아무 의미가 없다.
문제는 **이 프로젝트의 대상인 소상공인 점주들도 대부분 마찬가지**라는 점이다. 개업 때
한전과 계약을 맺긴 했지만, 평소에 "우리 가게 계약전력이 몇 kW"를 의식하며 장사하지 않는다.

여기에 빨간 "위험" 배지까지 붙으면 **이해 없는 공포**만 남는다. 무엇이 위험한지, 지금
당장 뭘 해야 하는지 알 수 없기 때문이다.

### 1-2. 다음 행동이 없다

"안전 점검을 부탁드립니다"는 사실상 아무것도 지시하지 않는다. 누구에게? 어떻게?
비용은? 지금 당장? — 이 질문에 답하지 못하면 알림은 무시되거나 불안만 남긴다.

---

## 2. 아이디어 — 감지에서 끝내지 말고 대응까지

점주 입장에서 자연스럽게 떠오르는 질문에 미리 답한다.

| 점주의 질문 | 시스템이 주는 답 |
|---|---|
| 무슨 일이 일어난 거지? | 전문용어 없는 일상어 설명 (`owner_sms`) |
| 그래서 뭘 하면 되지? | 지금 할 수 있는 조치 2~3가지 (`next_steps`) |
| 어디에 물어보지? | 그대로 보낼 수 있는 문의 초안 (`inquiry_draft`) |
| 돈이 더 나오나? | 초과 사용이 반복될 때의 요금 영향 안내 |

**흐름은 점주가 아니라 관리자에서 시작한다.** 점주가 이상을 느껴 문의하는 게 아니라,
관제 화면에서 관리자·담당자가 먼저 감지하고 점주에게 안내를 보내는 사전 대응 구조다.

---

## 3. 구현 — 대상별로 언어를 나눴다

같은 사건이라도 읽는 사람이 다르면 문장이 달라야 한다.

| 필드 | 대상 | 문체 |
|---|---|---|
| `owner_sms` | 점주 | **전문용어 금지.** 계약전력/%/KEC/kWh 없이 일상어 |
| `next_steps` | 점주 | 완결된 문장으로 "무엇을 왜" |
| `inquiry_draft` | 점주 → 한전·전기업체 | 복사해서 그대로 보낼 수 있는 형태 |
| `admin_note` | 관리자·전기담당자 | **반대로 전문용어 유지.** 규칙명·수치 정확히 |
| `emergency_report` | 소방·신고 접수 | 근거 수치와 규정 포함 |

### 3-1. 실제 생성 결과 (2026-09-10, `google/gemma-4-31b-it`)

> **점주 문자**: 충북식당 사장님, 영업시간이 아닌 새벽 시간대에 매장 전기 설비가 감당할
> 수 있는 양보다 훨씬 많은 전기가 한 시간 넘게 계속 쓰였습니다. 전기 설비에 무리가 가거나
> 과열될 수 있으니, 전문가를 통해 전기 점검을 받아보시길 권해드립니다.
>
> **문의 초안**: 안녕하세요, 충북식당입니다. 최근 영업시간 외 새벽 시간대에 계약전력을
> 초과하여 전기를 사용했다는 안내를 받았습니다. 저희 매장이 서류만으로 증설이 가능한
> 대상인지, 아니면 분전함 교체 같은 내선공사가 필요한 상황인지 확인하고 싶습니다.
>
> **관리자용**: KEC 212.3 표 212.3-2 산업용 배선차단기 기준 발동. 관측 전력량 18.95kWh가
> 임계치 14.62kWh를 초과하여 60분간 지속됨.

점주 문자에서 전문용어가 사라지고, 관리자용에는 그대로 남은 것을 확인할 수 있다.

### 3-2. 프롬프트 교정 기록

"계약전력·%·KEC를 쓰지 마시오"라는 **부정 지시만으로는 모델이 계속 용어를 되뱉었다.**
나쁜 예와 좋은 예를 직접 보여주는 방식으로 바꾼 뒤에야 교정됐다.

```
나쁜 예: "전력 사용량이 18.95kWh로 계약전력(45kW)의 130%를 초과했습니다."
좋은 예: "어젯밤 문을 닫으신 시간에, 매장 전기설비가 감당하도록 되어 있는 양보다
         훨씬 많은 전기가 한 시간 넘게 계속 쓰였습니다."
```

## 4. 제도 안내를 모델에게 맡기지 않은 이유

`next_steps`·`inquiry_draft`는 제도·절차를 언급한다. 그런데 **"이런 제도가 있습니다"류의
서술형 환각은 기계가 잡을 수 없다.** 숫자 환각은 `verify_numbers()`가 대조로 잡지만,
없는 제도를 지어내는 건 대조할 대상이 없다.

그래서 **제도 사실을 프롬프트에 통째로 넣어주고(`OWNER_GUIDANCE`) "여기 있는 것만 쓰라"고
못박았다.** 모델의 역할은 "아는 것을 꺼내오기"가 아니라 "주어진 사실 중 이 상황에 맞는 것을
골라 문장으로 만들기"로 한정된다.

### 4-1. 프롬프트에 넣은 사실과 출처

| 사실 | 출처 |
|---|---|
| 계약전력 = 한전이 공급하기로 한 용량, 배선·차단기가 그에 맞춰 설치됨 | 요기요 파트너 |
| 초과 반복 시 증설 안내문 → 그 뒤 초과요금 | 배민 사장님센터 / 요기요 파트너 |
| 건물 여유 용량 있으면 서류(건물주 날인·임대차계약서)만으로 증설 | 배민 사장님센터 |
| 여유 없으면 분전함 교체 등 내선공사 필요 | 배민 사장님센터 |
| 24시간 매장은 '720시간 특례' 신청 가능 | 배민 사장님센터 / 요기요 파트너 |
| 계약전력 20kW 이상은 한전도 15분 단위 피크 확인 | 요기요 파트너 |
| 문의: 한전 고객센터 123(24시간), cyber.kepco.co.kr | 한국전력공사 |

- [배달의민족 사장님센터 — 전기 증설 가이드](https://ceo.baemin.com/knowhow/11020)
- [요기요 파트너 — 음식점 전기요금·계약전력 계산방법](https://partner.yogiyo.co.kr/content/view/%EC%9D%8C%EC%8B%9D%EC%A0%90-%EC%A0%84%EA%B8%B0%EC%9A%94%EA%B8%88-%EA%B3%84%EC%95%BD%EC%A0%84%EB%A0%A5-%EA%B3%84%EC%82%B0%EB%B0%A9%EB%B2%95)
- [한국전력공사 고객소통 안내](https://www.kepco.co.kr/home/customer/csinformation/conts.do)

**주목할 연결점**: 한전도 계약전력 20kW 이상 고객을 **15분 단위**로 확인한다. 우리 AMI
데이터 주기와 정확히 같다 — 같은 데이터를 요금이 아니라 안전 목적으로 쓰는 것이 이
프로젝트의 차별점이라는 서사와 맞물린다.

### 4-2. 검증기는 그대로 작동한다

안내사항의 수치(123, 720, 20 등)를 허용 집합에 넣으면서 검출력이 무뎌지지 않았는지
재확인했다. 허용 집합은 24개로 여전히 좁다.

| 문장 | 판정 |
|---|---|
| 한전 고객센터 123으로 문의하세요 | 통과(안내사항 근거) |
| 24시간 매장은 720시간 특례를 신청할 수 있습니다 | 통과(안내사항 근거) |
| 초과요금 **47만원**이 부과됩니다 | **검출** |
| 지난 **5일간 9회** 발생했습니다 | **검출** |
| 예상 피해액 **350만원** | **검출** |
| 내부 온도가 **78도**까지 올랐습니다 | **검출** |

금액·기간처럼 점주가 가장 민감하게 받아들일 수치를 지어내는 경우가 여전히 걸린다.

## 5. 한계 (발표 시 명시할 것)

1. **실제 상담을 대체하지 않는다.** 증설 가능 여부·비용은 건물 상태에 따라 달라지므로
   반드시 한전·전기공사 업체 확인이 필요하다. 생성된 문의 초안은 말 그대로 초안이다.
2. **출처가 공식 문서가 아니다.** 배민·요기요의 소상공인 안내 콘텐츠를 근거로 했다.
   실제 서비스라면 한전 약관·요금표를 1차 출처로 삼아야 한다.
3. **비용을 계산해 주지 않는다.** "얼마 더 나오나?"가 점주의 최대 관심사지만, 요금 계산은
   계약종별·계절·시간대가 얽혀 있어 지금 데이터로는 근거 있는 답을 못 한다. 지어내는
   것보다 말하지 않는 편이 낫다고 보고 의도적으로 뺐다.
4. **발송 기능은 없다.** 문자·메일을 실제로 보내지 않는다. 화면에서 초안을 복사하는 데까지다.
